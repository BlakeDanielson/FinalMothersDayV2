Place your logo file here as `source.png` (preferred 1024x1024 PNG with transparent background and padding).

Then run:

```
cd ../../
npm run generate:icons
```

This will create:
- icon-192x192.png
- icon-512x512.png
- icon-maskable-192x192.png
- icon-maskable-512x512.png
- apple-touch-icon.png (180x180)
And two favicons in `public/`:
- favicon-32x32.png
- favicon-16x16.png
